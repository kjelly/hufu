# Archived documentation

These files are retained for migration history, incident evidence, or design
provenance. They are not active implementation specifications. Before using an
archived recommendation, verify it against code, tests, and the active map in
[`docs/README.md`](../README.md).

- `superseded-specs/`: replaced architecture or consumer contracts;
- `implementation-plans/`: completed or superseded implementation plans;
- `migration-reports/`: historical cutover and compatibility evidence;
- `roadmaps/`: retired large backlogs;
- `analyses/`: investigations and proposals.

The archive is intentionally not a second source of truth. Its original
wording is preserved where practical so that old decisions and incidents can
still be reconstructed.

# Implementation Plan - Fix and Optimize Automatic Skill Discovery

This plan details the changes required to fix critical bugs and complete integrations for the automatic skill discovery feature in **hufu**.

## Proposed Changes

### Component: Coordinator (internal/team)

#### [MODIFY] [coordinator.go](file:///home/ubuntu/nfs/github/agent-team-cli/internal/team/coordinator.go)
- Initialize the sidecar instance correctly during coordinator construction by calling `c.Sidecar()` instead of passing `c.sidecarInst` (which is lazily initialized and thus always `nil` at construction time).
- Add a getter method `SkillDetector()` to expose the `*skill.SkillPatternDetector` from the `Coordinator` struct.

```diff
-	// Enable sidecar for skill pattern detection
-	if c.sidecarInst != nil {
-		c.skillDetector.SetSidecar(context.Background(), c.sidecarInst)
-	}
+	// Enable sidecar for skill pattern detection
+	if s := c.Sidecar(); s != nil {
+		c.skillDetector.SetSidecar(context.Background(), s)
+	}
```

```go
// SkillDetector returns the coordinator's skill pattern detector.
func (c *Coordinator) SkillDetector() *skill.SkillPatternDetector {
	return c.skillDetector
}
```

---

### Component: Skill Detection (internal/skill)

#### [MODIFY] [discovery.go](file:///home/ubuntu/nfs/github/agent-team-cli/internal/skill/discovery.go)
- Refactor `mergeSimilarSequences` to use the `clusters` mapping generated by the Sidecar LLM semantic clustering.
- Map each description to its cluster ID. If candidates have the same tool sequence AND their descriptions belong to the same cluster (or share a cluster mapping), they are grouped and merged.
- Candidates with the same tool sequence but different clusters will remain separate skill draft candidates.

#### [MODIFY] [discovery_test.go](file:///home/ubuntu/nfs/github/agent-team-cli/internal/skill/discovery_test.go)
- Update `TestSkillPatternDetector_MergeSimilarSequences` to cluster all candidate description indices together (`0: {0, 1, 2}`) to ensure they merge correctly under the new logic.
- Add a new test case `TestSkillPatternDetector_MergeSimilarSequences_DifferentClusters` where candidates have the same tool sequence but different clusters, verifying that they are NOT merged.

---

### Component: Reporting (cmd/hufu)

#### [MODIFY] [report.go](file:///home/ubuntu/nfs/github/agent-team-cli/cmd/hufu/report.go)
- Import `"github.com/anomalyco/hufu/internal/skill"`.
- Implement `gatherSkillPatterns` to retrieve detected skill candidates from the coordinator's `SkillDetector()` and format them into `SkillPatternReport` structs for inclusion in the generated markdown report.
